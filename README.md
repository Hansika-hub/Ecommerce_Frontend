# E-Commerce Frontend

A React-based frontend for an e-commerce application, built with Vite.
The application provides the client-side interface and communicates with
the backend through HTTP requests using Axios.

## Technology Stack

-   **React 19** -- UI development
-   **Vite** -- Development server and build tooling
-   **React Router DOM** -- Client-side routing
-   **Axios** -- HTTP communication with the backend
-   **JavaScript (ES Modules)**

## Prerequisites

-   Node.js (LTS recommended)
-   npm
-   Git

## Getting Started

### 1. Clone the repository

``` bash
git clone https://github.com/Hansika-hub/Ecommerce_Frontend.git
cd Ecommerce_Frontend
```

### 2. Install dependencies

``` bash
npm install
```

### 3. Start the development server

``` bash
npm run dev
```

Open the local URL printed in the terminal (Vite typically uses
`http://localhost:5173`).

## Backend Integration

This frontend is intended to work with the companion backend:

[Ecommerce_Backend](https://github.com/Hansika-hub/Ecommerce_Backend)

Ensure the backend is running and that the API base URL used by the
frontend is configured to point to your backend instance. Check the
source configuration for the expected URL or environment variable name.
